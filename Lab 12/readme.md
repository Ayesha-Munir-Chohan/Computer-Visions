# Applied Machine Learning Case Studies Portfolio

## Overview

This repository presents multiple applied machine learning case studies focused on solving real-world problems across different industries using preprocessing, statistical analysis, and predictive modeling techniques.

The project demonstrates practical implementation of:

- Standardization and Feature Scaling
- Auto-Correlation Analysis
- Feature Weighting and Importance
- Classification Models
- Sensor Data Analysis
- Intrusion Detection Systems

---

# Domains Covered

| Domain | Objective | Techniques |
|--------|-----------|-------------|
| Healthcare | Predict patient cardiac risk | StandardScaler, Logistic Regression |
| Agriculture | Forecast seasonal crop yield | Auto-Correlation |
| Finance | Assess creditworthiness | Logistic Regression Feature Weights |
| Manufacturing | Detect machine anomalies | Scaling + Auto-Correlation |
| Cybersecurity | Detect network intrusions | Random Forest + Feature Importance |
